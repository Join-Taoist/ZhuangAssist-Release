# ZhuangAssist 0.8.1

程序集 `0.8.1.0` · Dalamud API Level 15 · 作者 Join-Taoist

修复战斗事件补全对象名称时可能触发的游戏崩溃。事件补全使用当帧已采集的数据，跳过无效对象引用，并保留事件原本携带的字段。名称改用有长度限制的读取方式，必要时从本地游戏数据查找。

本版包含 0.8.0 的完整功能，包括外部 C# 脚本管理、JSON 目录更新、Imgui 与原生 Vfx、颜色和透明度设置、原生 Omen、文字和 SE 音效，以及可选 Edge TTS。已安装客户端可在卫月中更新，原有脚本和设置可直接沿用。[0.8.0 版本说明](https://github.com/Join-Taoist/ZhuangAssist-Release/blob/main/releases/0.8.0.md)

- 普通构建、混淆构建和安装 ZIP 各通过 120 项离线检查。
- 使用当前卫月 SDK 编译 65 份本机外部脚本，并验证流式宿主中的脚本 API 绑定。
- 两个 ZA 程序集均经过混淆。安装包随附第三方说明、许可和逐文件校验表，ZIP 的 SHA-256 见 Release 附件 `SHA256SUMS.txt`。

长时间战斗的稳定性仍待进一步观察。
