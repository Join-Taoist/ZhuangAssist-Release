# ZhuangAssist 0.6.0 — 首次公开安装包

程序集版本：0.6.0.0；Dalamud API Level：15；命令：`/za`。

本版提供本地 C# 脚本编译和加载、脚本启停与参数保存、游戏事件分发、Imgui 与原生 Vfx 绘图、文字与 Windows 本地语音，以及独立的 JSON 脚本目录下载、安装和更新。脚本以外部文件加载，安装包不内置第三方战斗脚本。

“设置 → 常规”可开启 Edge TTS，配置音色、语速、语调、音量和预览播放。在线语音默认关闭；本地脚本、绘图和提示启动不依赖在线语音服务。首次在线合成会把待朗读文本交给微软语音服务处理。

## 验证分类

- 已编译：Release 0.6.0.0，依照 API Level 15 的本机 SDK 构建。
- 已通过离线检查：63 项运行时检查，59/59 本地脚本样本编译与流式宿主 API 绑定；公开包还会从实际压缩包解压后复核依赖、清单、文件校验值及流式宿主编译。
- 已通过联网检查：Edge 正式后端真实合成、MP3 解码和再次命中缓存；该检查没有播放声音。
- 已有游戏内反馈：前序本地构建的模拟脚本箭头与五秒清理、脚本重载和开关清理、部分真实事件字段，以及 Vfx 预览和隐藏界面后继续显示得到确认。反馈不代表全部脚本或副本机制兼容。
- 待游戏内验收：公开仓库安装渠道、此版本的完整生命周期、所有绘图形状与副本行为、Edge TTS 实际发声和热更期间声音清理。编译成功不等于游戏内实测通过。

## 已知限制

任意 VfxMethod 原生特效编辑、头顶标记、脚本 HTTP 工具、每个敌人的仇恨排序，以及原版时间轴编辑/录制和完整 DSL 尚未完整恢复；部分事件与字段仍需游戏内核验。相关能力不会用空方法或固定成功掩盖。

## 安装

在卫月自定义插件仓库添加根目录 README 中的 pluginmaster.json 地址，刷新后搜索 ZhuangAssist。已经使用同名开发插件时，先停用开发插件再使用仓库版，避免重复实例。首次运行用 `/za` 打开“脚本地址”，添加自己的 JSON 目录并下载脚本。

安装包根目录直接包含 ZhuangAssist.dll 和 ZhuangAssist.json，不包含私人配置、脚本缓存、SDK、原插件 DLL、验证库或调试符号。压缩包 SHA-256 见 Release 附件 SHA256SUMS.txt；包内逐文件校验值见 SHA256.json。
