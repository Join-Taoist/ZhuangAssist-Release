# ZhuangAssist 0.8.0

作者：Join-Taoist。程序集版本：0.8.0.0；Dalamud API Level：15；命令：`/za`。

本次正式版汇总此前公开版 0.6.0 之后的全部本地功能和修复。公开包的 ZA 主程序集与语音核心均经过 Obfuscar 2.2.50 混淆；保留现有外部脚本所需的公开类型、方法、命名参数和配置字段。

## 脚本管理

- 合并为“可用脚本”卡片，支持搜索、选择下载、更新、启停、删除，以及简介、用户设置和方法设置。
- 当前地图明确所属的脚本按“未安装 → 可更新 → 已安装”优先；全局及其他地图保留更新/安装颜色分组和激活先后顺序。
- 打开列表时可后台检查目录，五分钟内避免重复请求；新增手动“检查脚本更新”。失败保留缓存和本地脚本，下载更新仍由用户触发。
- 安装或更新保留原路径、启停和参数；下载成功清理待下载选择，整个搜索批次成功后清空当次搜索。
- 布尔参数使用开关，字符串直接编辑，ScriptColor 支持 RGBA、透明度及预览；说明文字和控件布局优化。垃圾桶直接删除脚本文件，不保留删除备份。

## 绘图、事件和提示

- Imgui 与原生 Vfx 分别处理，恢复默认模式、颜色、透明度、预览和相关绘制选项。
- 补齐 VfxMethod.CreateOmen 及所属句柄的颜色、位置/朝向、缩放、速度、显隐、回调、移除和资源清理。
- 改进世界投影、近裁剪、纹理/绘制状态隔离及大量顶点的索引边界处理。
- 处理没有咏唱/状态组件的对象，局部读取失败不会阻断已排队事件；保留真实错误计数和限频日志。
- 本地 `/e`、`/echo` 支持 SE1～SE16，重复标签保留，队列执行前检查脚本作用域和总开关。`/za se` 可立即检查 SE1。
- 保留本地文字、Windows 语音、可选 Edge TTS 设置和缓存；核心启动和本地脚本不依赖在线服务。

## 验证分类

- Release 构建、公开 API/命名参数/资源一致性及调试信息排除检查。
- 116 项离线检查同时用于普通构建和混淆后的正式 DLL，覆盖脚本运行、更新回退、参数持久化、事件、绘图提交、语音路由及卸载清理。
- 本机 64/64 外部脚本使用当前 SDK 编译，通过空 Assembly.Location 的流式宿主及同一份 ScriptAccessory 绑定检查。
- 安装包从实际 ZIP 解压复验，发布后重新下载并与本地热加载文件核对版本、SHA-256 和模块标识。
- 前序游戏内反馈已确认模拟箭头、五秒清理、部分真实事件字段、Vfx 预兆及 SE1 实际发声。这些反馈不代表所有脚本或机制均已实测。

## 已知限制

头顶标记、敌人仇恨排序、LockOn/Channeling 角色特效、脚本 HTTP 工具、部分事件、时间轴编辑/录制和完整 DSL 尚未完整恢复。其他游戏内置聊天命令和非 echo 频道可能被拒绝。未知功能保持真实错误，不返回固定成功。

旧版方法开关的哈希无法可靠转换时需要手动核对。任意脚本的直接内存操作、外部插件、动态反射、自建线程及全部战斗行为不由编译通过保证。复杂场景的特效遮挡、特定视角绘图、每个副本机制及 Edge 实际发声仍需各自验收。

安装包不包含第三方脚本、个人配置、源码、PDB 或混淆映射。原版与第三方来源说明及必要许可随包保留。
